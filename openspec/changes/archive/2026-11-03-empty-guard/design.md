## Варианты реализации неактивной кнопки

Кнопка «Добавить» уже имеет в CSS обработанный состояний `:disabled`
(`client/src/components/NewCardForm/NewCardForm.module.css`, строка 38-40):
`opacity: 0.5; cursor: not-allowed`. Это позволяет использовать два подхода.

### Вариант 1: атрибут `disabled` на `<button>`

Добавить условный атрибут `disabled={title.trim() === ""}` на `<button>`
в `NewCardForm.tsx`. Браузер автоматически:
- блокирует событие `onClick`
- устанавливает `cursor: not-allowed` (уже есть в CSS)
- делает кнопку недоступной для навигации с клавиатуры (Tab)
- передаёт состояние `disabled` в `:disabled` псевдокласс CSS

**Плюсы:**
- нативное поведение браузера, без дополнительного JS
- встроенная доступность (accessibility): скринридеры сообщают о неактивности
- уже готовый CSS-стиль `:disabled`
- минимум кода: одна строчка

**Минусы:**
- `disabled` кнопка не получает `:hover`-эффекты (но это ожидаемо)

### Вариант 2: только CSS-класс `.button--inactive`

Добавить класс `.button--inactive` с нужными стилями и переключать его
через `className`. Обработчик `handleAdd` остаётся без изменений —
проверка `title.trim() === ""` уже есть.

**Плюсы:**
- кнопка остаётся кликабельной для JS-обработчика
- можно стилизовать `:hover` независимо

**Минусы:**
- дублирует логику: проверка есть в JS, но клик всё равно проходит
- нет нативной блокировки `onClick` — пользователь может нажать и ничего не произойдёт
- скринридеры не узнают о неактивности
- больше кода и стилей

### Выбранный вариант: атрибут `disabled`

Выбран **Вариант 1** — он проще, надёжнее и использует встроенные
механизмы браузера. CSS-стиль `:disabled` уже готов в
`NewCardForm.module.css`, менять стили не нужно.

## Вариант с текстом ошибки — отклонён

Альтернативный подход — показывать текст ошибки под полем ввода
(например, «Введите название карточки») вместо визуального изменения
кнопки.

**Почему отклонён:** постановка исключила этот вариант. Требование
спецификации — кнопка «Добавить» SHALL выглядеть неактивной, а не
показывать текст ошибки. Визуальная недоступность кнопки — достаточный
индикатор для пользователя.
