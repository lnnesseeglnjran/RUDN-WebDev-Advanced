## Why

На канбан-доске пользователь не может удалить карточку — ни ошибочно созданную, ни утратившую актуальность. Это ограничивает управление содержимым доски и вынуждает оставлять мусор среди задач.

## What Changes

- На каждой карточке появляется кнопка для удаления
- Пользователь может удалить карточку через кнопку на карточке с подтверждением в диалоге
- При отказе от удаления карточка остаётся на доске
- При ошибке сервера карточка остаётся на доске
- Удалённая карточка исчезает с доски без перезагрузки страницы

## Capabilities

### New Capabilities
- `card-deletion`: на доске пользователь может удалить карточку через кнопку на карточке с подтверждением; при отказе или ошибке сервера карточка остаётся на доске; удалённая карточка исчезает без перезагрузки

### Modified Capabilities
- (нет — требования существующих спецификаций не меняются)

## Impact

- **UI:** карточки на доске получают элемент удаления
- **Данные:** карточка удаляется с сервера и исчезает из отображения
