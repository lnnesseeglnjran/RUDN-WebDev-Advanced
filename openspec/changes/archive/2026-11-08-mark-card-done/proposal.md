## Why

На канбан-доске карточки нельзя отмечать выполненными. У карточки есть признак `isDone` — такие карточки на доске приглушены и зачёркнуты, а фильтр в шапке умеет их прятать, — но поставить эту отметку невозможно. Из-за этого признак приходит с сервера и никак не меняется, а фильтр бесполезен.

## What Changes

- На карточке появляется элемент управления (чекбокс) для переключения отметки «выполнено»
- Сервер принимает отдельный эндпоинт для изменения поля `isDone` конкретной карточки
- Отметка сохраняется на сервере: после обновления страницы карточка остаётся в том же состоянии
- Запрос с негодным значением отклоняется кодом 400

## Capabilities

### New Capabilities
- `mark-card-done`: на карточке есть элемент управления для переключения отметки «выполнено»; сервер принимает и сохраняет это изменение отдельным эндпоинтом

### Modified Capabilities
- (нет — требования существующих спецификаций не меняются)

## Impact

- **Клиент:** `BoardCard.tsx` — добавить элемент управления; `api/cards.ts` — добавить функцию для PATCH-запроса; проброс `id` и коллбека через `BoardColumn` → `BoardCard`
- **Сервер:** `cards.service.ts` — добавить функцию обновления `isDone`; `cards.controller.ts` — добавить обработчик; `cards.routes.ts` — добавить PATCH-роут; `validateDoneToggle.ts` — middleware валидации
- **Данные:** изменение затрагивает только поле `isDone` карточки
