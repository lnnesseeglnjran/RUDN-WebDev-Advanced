## Why

На канбан-доске пользователь не видит, сколько карточек на ней создано. Заголовок «Канбан-доска» не несёт никакой количественной информации, что затрудняет быструю оценку объёма задач. Нужно добавить счётчик карточек рядом с названием доски.

## What Changes

- В компоненте `BoardHeader` отобразить счётчик общего числа карточек рядом с заголовком «Канбан-доска»
- Счётчик считает все карточки без фильтрации по `isDone`
- Счётчик обновляется автоматически после добавления новой карточки
- Формат отображения: число в скобках, например «Канбан-доска (4)»
- Во время загрузки карточек заголовок отображается без числа: «Канбан-доска»

## Capabilities

### New Capabilities
- `board-card-counter`: на доске отображается счётчик общего числа карточек рядом с заголовком; счётчик обновляется при любом изменении данных через React Query

### Modified Capabilities
- (нет — требования существующих спецификаций не меняются)

## Impact

- **UI:** `client/src/components/BoardHeader/BoardHeader.tsx` — добавить отображение счётчика; `client/src/components/BoardHeader/BoardHeader.module.css` — стили для счётчика
- **Data flow:** `client/src/App.tsx` — передать количество карточек в `BoardHeader` (через props или напрямую из `useQuery`)
- **Data source:** `client/src/api/cards.ts` — без изменений, данные уже загружаются через `fetchCards()`
- **Мок-сервер:** `client/db.json` — без изменений
