## Purpose

Отображает на доске счётчик общего числа карточек рядом с заголовком, чтобы пользователь мог быстро оценить объём задач.

## ADDED Requirements

### Requirement: Счётчик карточек отображается в шапке доски
Система SHALL отображать общее число карточек на доске рядом с заголовком «Канбан-доска» в формате «Канбан-доска (N)», где N — количество всех карточек.

#### Scenario: Счётчик показывает правильное число карточек
- **WHEN** на доске загружено N карточек
- **THEN** в заголовке отображается «Канбан-доска (N)»

#### Scenario: Счётчик показывает ноль при отсутствии карточек
- **WHEN** на доске нет карточек
- **THEN** в заголовке отображается «Канбан-доска (0)»

### Requirement: Счётчик учитывает все карточки
Система MUST считать все карточки на доске без фильтрации по статусу выполнения (`isDone`).

#### Scenario: Счётчик включает выполненные карточки
- **WHEN** на доске есть карточки с `isDone: true` и `isDone: false`
- **THEN** счётчик отображает сумму всех карточек

### Requirement: Счётчик обновляется при добавлении карточки
Система SHALL автоматически обновлять значение счётчика после добавления новой карточки.

#### Scenario: Счётчик увеличивается при добавлении карточки
- **WHEN** пользователь создаёт новую карточку
- **THEN** значение счётчика увеличивается на 1 без перезагрузки страницы

### Requirement: Счётчик не показывается во время загрузки
Система SHALL отображать заголовок «Канбан-доска» без числа, пока карточки загружаются.

#### Scenario: Заголовок без числа при загрузке
- **WHEN** карточки ещё загружаются (данные не получены)
- **THEN** в заголовке отображается «Канбан-доска» без скобок и числа
