## Purpose

Описывает, как сервер обрабатывает удаление карточки и возвращает JSON-ответы для неизвестных маршрутов и ошибок.

## ADDED Requirements

### Requirement: Удаление карточки по идентификатору из пути
Сервер SHALL принимать идентификатор удаляемой карточки из пути запроса и удалять соответствующую карточку.

#### Scenario: Успешное удаление карточки
- **WHEN** получен запрос на удаление карточки с существующим идентификатором
- **THEN** карточка удаляется и сервер возвращает статус 204 без тела

### Requirement: Удаление несуществующей карточки
Сервер SHALL возвращать статус 404 и JSON с описанием ошибки при удалении карточки, которой нет.

#### Scenario: Удаление несуществующей карточки
- **WHEN** получен запрос на удаление карточки с несуществующим идентификатором
- **THEN** сервер возвращает статус 404 с JSON-описанием ошибки и продолжает работать

### Requirement: Удалённая карточка не возвращается в списке
Сервер SHALL не возвращать удалённую карточку при повторном запросе списка карточек.

#### Scenario: Удалённая карточка отсутствует в списке
- **WHEN** карточка удалена и получен запрос на список карточек
- **THEN** удалённая карточка не появляется в ответе

### Requirement: JSON-ответ для неизвестных маршрутов
Сервер SHALL возвращать статус 404 и JSON-ответ для любого неизвестного маршрута вместо HTML.

#### Scenario: Запрос на неизвестный маршрут
- **WHEN** получен запрос на маршрут, который не определён на сервере
- **THEN** сервер возвращает статус 404 с JSON-описанием ошибки

### Requirement: JSON-ответ при неожиданной ошибке
Сервер SHALL возвращать статус 500 и JSON-ответ при любой неожиданной ошибке.

#### Scenario: Неожиданная ошибка сервера
- **WHEN** происходит непредвиденная ошибка при обработке запроса
- **THEN** сервер возвращает статус 500 с JSON-описанием ошибки
