## Why

После переезда на собственный сервер удаление карточек не работает: сервер отвечает 404 и присылает HTML вместо JSON. Фронтенд пытается удалить карточку через DELETE /api/cards/:id, но сервер не поддерживает этот метод и не возвращает JSON-ответы для неизвестных маршрутов.

## What Changes

- Сервер начинает поддерживать удаление карточки по идентификатору
- Сервер возвращает статус 204 без тела при успешном удалении
- Сервер возвращает JSON-ответы для неизвестных маршрутов вместо HTML
- Сервер возвращает статус 500 и JSON при неожиданной ошибке
- Клиент получает корректный JSON при обращении к несуществующему маршруту и при ошибке

## Capabilities

### New Capabilities
- `server-delete-card`: сервер поддерживает удаление карточки по идентификатору, возвращая статус 204 без тела при успехе
- `server-error-responses`: сервер возвращает JSON-ответы для неизвестных маршрутов и ошибок вместо HTML

### Modified Capabilities
- (нет — требования существующих спецификаций не меняются)

## Impact

- **Сервер:** добавление роута удаления и обработчика неизвестных маршрутов
- **Клиент:** без изменений, клиент уже отправляет DELETE-запрос
